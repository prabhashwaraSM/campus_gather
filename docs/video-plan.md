# Demonstration plan — 9 minutes

Prepare the database, create an organiser account, and open the website before recording. Do not show passwords. Use a new disposable test event to demonstrate CRUD.

| Time | Demonstration |
| --- | --- |
| 0:00–0:45 | Introduce the team, real-world problem and solution |
| 0:45–1:45 | Browse events, search, filter by category and view details |
| 1:45–2:15 | Sign in as organiser without showing the password |
| 2:15–3:15 | Create a future event and show it in the list and database |
| 3:15–4:00 | Edit its venue; show the saved result |
| 4:00–4:45 | Delete the test event; show that it is gone |
| 4:45–5:30 | Show validation, empty search and mobile-width layout |
| 5:30–6:45 | Explain HTML/CSS/JS/PHP/MySQL, config.php, PDO and one form submission |
| 6:45–8:30 | Each member explains actual contributions and relevant files |
| 8:30–9:00 | Summarise limitations and learning outcomes |

Record the real running PHP application, not slides alone. Keep the final video between 8 and 10 minutes. One member uploads source, report, completed contributions text file and video for the whole group.
